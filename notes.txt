Decided order for install.sh (2026-09-20, from the install-script interview)
================================================================================

  1  preflight: OS, not root, sudo works
  2  prerequisites: Mac = Xcode command line tools + brew; Ubuntu = apt basics + Linuxbrew
  3  brew bundle --no-upgrade: Brewfile, then Brewfile.mac on a Mac
  4  toolchains: bun, pnpm, nvm (default-packages symlink, nvm install --lts)
  5  globals: bun.txt, pnpm.txt (npm.txt arrives through nvm default-packages)
  6  oh-my-zsh clone + bootstrap/omz-plugins.txt
  7  mkdir -p ~/.config ~/.config/opencode. Real dirs BEFORE stow, so stow links the
     files instead of folding the whole dir into the repo; folded, rtk/icm would
     write plugins/ and skills/ into the repo (tested in a throwaway HOME).
  8  stow. Files that conflict are moved to ~/.dotfiles-backup/<timestamp>/ first;
     never --adopt.
  9  Linux only: /opt/homebrew symlink, iterm2 stub, stow --ignore list
 10  agent CLIs: Claude Code and opencode from the vendors' official installers,
     every run, skipped when already on PATH (verify the URLs against vendor docs)
 11  mkdir -p ~/.claude; ~/.local/bin and ~/.opencode/bin on PATH; then rtk init,
     icm init, wt config shell install zsh
 12  Linux: chsh to zsh. Print the manual checklist: claude and opencode login,
     gh auth login, SSH keys.

  Re-runs only add what's missing: brew bundle --no-upgrade, never delete.
  Flags: --dry-run, --upgrade, --check-cleanup (prints, never removes), --skip <step>.
  Claude Code's settings.json is not managed. Opencode's opencode.json and tui.json
  are stowed from AI/.
  Testing: --dry-run and a real no-op re-run on the Mac; the Linux path is tested by
  hand on a VPS (no Docker).
